1. Server migration to the versioned layout
-------------------------------------------

02:09  First attempt (commit 1534635) rolled itself back:

    curl: (22) The requested URL returned error: 404
    Versioned site validation failed; restoring the previous Nginx configuration.
    Error: migration validation failed; the legacy Nginx configuration was restored

Cause: `systemctl reload nginx` returns before the old workers exit. The check
ran immediately and reached a worker still serving /var/www/html, which has no
VERSION. A manual switch with a 2-second wait served the expected version:

    legacy-20261010T020952Z

Fixed in commit e66bae9 (#10): retry the VERSION check for up to 10 seconds.

2. Run #1, attempt 1: OIDC role assumption denied
-------------------------------------------------

Run: https://github.com/estennio/aws-devops-infrastructure-lab/actions/runs/38016600883/attempts/1

    Error: Could not assume role with OIDC: Not authorized to perform sts:AssumeRoleWithWebIdentity

CloudTrail (us-east-2), event AssumeRoleWithWebIdentity, 02:21:56:

    "errorCode": "AccessDenied"
    "userName": "repo:estennio@263081306/aws-devops-infrastructure-lab@1411264152:environment:production"

The trust policy expected the legacy subject
`repo:estennio/aws-devops-infrastructure-lab:environment:production`.
GitHub issues the immutable subject (owner and repository IDs) for
repositories created after 2026-07-15. Fixed in commit e234bb0 (#11); the
Terraform plan changed only `assume_role_policy` (0 add, 1 change, 0 destroy).
